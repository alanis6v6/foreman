# 盤點工單範本（只讀）

**你的唯一職責**：只讀 ＿＿＿ repo，回報「骨架」與「技債清單」兩份草稿。不改、不推、不開 PR。

**做法**
- 找出最新的開發分支（預設分支跟其他分支誰比較新），以它為準，回報分支與 commit
- 先讀 CLAUDE.md／AGENTS.md、README、docs/，回報已經有哪些文件、哪些過時

**骨架**
1. 目錄樹到第二層，每個資料夾一句話：放什麼、屬於哪個 target
2. 每個程式檔：行數、一句話職責；列前 20 大
3. 超過 400 行的檔：裡面有哪幾塊責任、建議拆成哪幾檔
4. 資料怎麼流：誰寫、誰讀、存在哪（以程式為準，附檔名:行號）
5. 測試：有哪些、測什麼、缺哪些

**技債**（每條：檔名:行號、是什麼、為什麼算債、怎麼還、S/M/L）
- 沒用到的程式、重複的邏輯、寫死的數字或字串、TODO／FIXME／HACK、繞過的編譯器或工具問題、過長的函式、散落的樣式
- 最後挑最該先還的 5 條，說理由

**回報格式**：只回傳結構化狀態與結果，禁止客套與情緒安撫。另列「做不到或不確定」。
