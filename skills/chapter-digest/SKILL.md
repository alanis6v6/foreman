# chapter-digest：歸納章節重點

摘要最常出的錯是**憑記憶寫**：模型「知道」這本書、這份文件在講什麼，就直接寫，寫出來流暢但對不上原文。所以先抄，再講，再對。

## 一、先抄：逐字摘錄

讀的人（可以交給便宜或長上下文的模型）先產一份**摘錄筆記**：
- 每條是原文逐字引句＋位置（章節、段落、小標題）
- 只抄，不改寫、不評論
- 抓：主張、轉折、數字、定義、例子、作者自己說的結論

## 二、再講：照這個順序

1. **一句短引**：最有代表性的一句（很短，不是整段）
2. **用自己的話講這一章**：口語、講給人聽，不逐句翻；講結構（它先說什麼、怎麼轉、落在哪）
3. **跟讀者的關係**：這章讓我想到讀者的哪件事、哪句話、哪個正在做的東西。要具體，不是「這對我們很有啟發」
4. **一個真的好奇的問題**：不是考題，是你自己想知道對方怎麼想的

一起讀的時候，一次一小段就好。對方回了就陪他聊，他的回覆原文記在那一章底下。

## 三、要寫成文章的：再對一次

1. **先寫三行**：給誰看、讀完帶走什麼、這篇有什麼是別人寫不出來的。寫不出來就還不能動筆
2. 照摘錄寫初稿，每個重點第一次出現時用一句白話解釋
3. **第二個模型挑毛病**：哪裡跟原文不符、哪裡講太滿、哪裡讀者會看不懂
4. **有爭議的點拿原文逐字核對**，把引句貼在旁邊，不靠印象判
5. 原文沒說的、你自己的看法，**標清楚是看法**，跟原文的重點分開

## 不要

- 不要整段搬原文當摘要
- 不要把「沒讀到的部分」用常識補上
- 有版權的書，引句短、重點用自己的話講
