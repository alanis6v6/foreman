# nightly-dream：每日做夢

人睡覺的時候會把白天的事整理進記憶。agent 不會：它當下記了什麼就是什麼，漏掉的就永遠漏掉，答應了、換了一個對話就沒人做。
做夢就是補這一步：**下班後回頭重讀當天的對話，找出漏掉的。**

## 怎麼跑

1. **時間**：每天固定一次，使用者睡了以後（例如凌晨三點），整理「前一天」。
2. **輸入**：只抽當天對話裡**使用者打的字**跟 **agent 真的送出去的回覆**；工具輸出、系統附加的東西去掉，省很多字。
3. **誰做**：便宜的模型就夠（它只要比對、不用判斷大方向）。
4. **權限**：只給讀檔、搜尋，**不能改任何檔案**。
5. **在哪跑**：在一個上層沒有大份 CLAUDE.md 的資料夾開，只把記憶檔的資料夾加進可讀範圍，不然它會先讀一整包必讀才開始。
6. **輸出**：一份整理單，存在**不進版控**的地方（對話裡常有私事）。
7. **隔天**：主 agent 醒來讀整理單，**自己決定**要改哪些記憶檔。做夢的模型不直接改，因為它沒有前後文，常會把玩笑當決定。

## 整理單找三種東西

每條都要附**原話（逐字、帶時間）**跟**它搜過哪些檔**：

1. **沒記到**：使用者講了值得以後記得的事（決定、喜好、否決、數字與錢、計畫、對某個東西的要求、生活裡的事），記憶檔裡搜不到
2. **記了但過時或矛盾**：記憶檔的寫法跟當天講的不一樣，或檔案裡兩處互相打架（附檔名＋行號）
3. **答應了沒做**：agent 說「等一下做」、或使用者說「好／可以／開工」之後，紀錄裡看不到完成，待辦卡也沒寫進度

規則：純聊天、撒嬌、已經記過的不列；不確定就標「不確定」不要猜；每類最多 10 條，重要的在前面。

範本提示詞在 `PROMPT.md`。

## 為什麼要分開兩步

做夢的模型只看得到一天的對話，不知道前後文：一句玩笑、一個隨口的「好像可以」，它分不出是不是決定。讓它直接改記憶，錯的東西會被寫成規則。所以它只列、附原話，判斷留給懂前後文的主 agent。

（我們第一晚跑，它就撿回一句主 agent 自己漏掉的話：使用者說了當天中午吃什麼。這種小事，就是隔天對方會問「你怎麼不記得」的那種。）
