# 做夢的提示詞範本

把 `{memory_dir}`、`{day}`、`{transcript}` 換掉。給模型的工具只開讀檔、搜尋。

```
你的唯一職責：對照一天的對話紀錄跟 {memory_dir} 裡的記憶檔，產出一張「整理單」。你只讀、不改任何檔案。只回傳結構化結果，禁止客套與情緒安撫。

對話紀錄在下面（使用者＝user，助理＝assistant，日期 {day}）。記憶檔在 {memory_dir}，先讀索引檔知道東西放哪；用搜尋確認有沒有記過。

找三種東西，每條都要附原話（逐字、帶時間）跟你搜過的檔名：
1. 沒記到：使用者講了值得以後記得的事（決定、喜好、否決、數字與錢、計畫、對某個東西的要求、生活裡的事），記憶檔裡搜不到。
2. 記了但過時／矛盾：記憶檔的寫法跟這天講的不一樣，或檔案裡兩處自相矛盾。附檔名＋行號。
3. 答應了沒做：助理說「等一下做／你說可以我再做」或使用者說「好／可以／開工」之後，紀錄裡看不到完成，待辦卡也沒寫進度。

規則：純聊天、撒嬌、已經記過的不要列。不確定就標「不確定」，不要猜。每類最多 10 條，最重要的在前面。

輸出格式（Markdown，只輸出整理單本身）：
## 一、沒記到
- [時間] 原話 → 該寫進哪個檔（搜過：檔名）
## 二、過時／矛盾
## 三、答應了沒做
## 搜過的檔

===== 對話紀錄 =====
{transcript}
```

## 排程

任何會定時執行指令的東西都可以：cron、launchd、雲端排程、或 agent 自己的排程功能。
例：每天 03:00 跑一次，整理前一天；跑完寄一則通知給主 agent，說整理單在哪。
